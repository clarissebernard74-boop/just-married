# Just Married

Site vitrine de **Just Married**, atelier de robes de mariée taillées dans des draps de trousseau anciens.
5 rue Duguesclin, 69006 Lyon.

- `index.html` : accueil, collection, configurateur sur-mesure « Just You », registre, atelier, rendez-vous
- `robe.html` : page de chaque robe (`robe.html?m=mathilde`, `?m=augustine`…), données dans la liste `ROBES`

Site statique, sans build : il suffit de servir le dossier.

Crédits : vidéos [Mixkit](https://mixkit.co), photos [Unsplash](https://unsplash.com) (licences libres).
